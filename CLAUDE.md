# Claude Code working rules

- Never reset, clean, commit, or push without asking.
- Keep code cross-platform.
- Never fabricate ratings, hours, prices, live events, addresses, availability, or travel times. Keep demo content labelled.
- Before reporting a visual change done, verify it in the simulator with your own recording using `xcrun simctl io booted recordVideo`.
- Read the project handoff at `docs/HANDOFF.md`, approved design at `docs/DESIGN.md`, and implementation status at `docs/TASKS.md`.
- Product decisions live in `docs/DECISIONS.md`; supplied Pass 3–9 specifications and asset readmes live in `docs/specs/`.
